# MiBudsClient macOS port

MiBudsClient was originally developed by **Cesur Polat** and the contributors to
[CesurPolat/MiBudsClient](https://github.com/CesurPolat/MiBudsClient). The upstream
Git history and the [GNU General Public License v3.0](LICENSE) are preserved.

**November 25, 2026.** This fork, maintained by [mcyrj](https://github.com/mcyrj),
adds macOS Bluetooth Classic support via IOBluetooth, a menu bar icon, and macOS
packaging. It also updates reconnection and battery refresh behavior, and turns
off automatic submission of new diagnostic reports.

The corresponding source and build instructions for each downloadable release
are available under its tag in the [public fork](https://github.com/mcyrj/MiBudsClient).
